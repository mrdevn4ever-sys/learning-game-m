# Prüfung: öffentlicher Teil

Dieser Ordner enthält **nur öffentliche** Abnahmekriterien:
- `gegenproben.md`: Gegenprobenkatalog je Fach und Nachweisform
- Freigabekriterien, die Produktagenten kennen dürfen und sollen

**Verdecktes Prüfmaterial** gehört nie in dieses Repository: konkrete Prüfaufgaben, Sollantworten, Ziehungen, verdeckte Handschriftfamilien und Freigabeschlüssel. Es liegt im separaten privaten Prüfbereich, auf den nur die Prüf-Identität Zugriff hat (Masterprompt, Abschnitte 6 und 7).
